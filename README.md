# ⚙️ Post Machine

This is a lightweight web project built entirely with vanilla web technologies. It is designed to be simple, fast, and completely independent of any bundlers, frameworks, or external libraries.

## 🌐 Live Preview

Explore the working project live on GitHub Pages: [View Live Site](https://ТВОЙ-НИК.github.io/post-machine/)

## 🚀 Technology Stack

* **Structure:** `HTML5` — Clean and semantic markup.
* **Styling:** `CSS3` — Custom styles written from scratch without CSS frameworks.
* **Logic:** `Vanilla JavaScript` — Pure JS for interactivity, with zero dependencies.

## ✨ Key Features

* **Zero Dependencies:** No npm, no build tools, just pure code.
* **Instant Load:** Extremely fast performance due to a minimalistic three-file structure.
* **Beginner Friendly:** Clean and easy-to-read codebase.
